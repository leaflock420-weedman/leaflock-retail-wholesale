Most common job — update prices on the order form

  1. Download the spreadsheet (button above, or Admin → Wholesale → Download spreadsheet).
  2. Open in Excel. Change prices or product names.
  3. Do not change the top header row.
  4. File → Save As → CSV (Comma delimited).
  5. Admin → Wholesale → Upload updated CSV.
  6. Check portal — the order form updates immediately.

If something goes wrong

  • Upload failed — usually duplicate SKU or missing price. Read the red message on Admin.
  • Excel looks wrong — save as CSV again, not .xlsx.
  • Portal looks old — hard refresh: Ctrl + Shift + R.
  • PayPal missing — Admin → System status (should show PayPal live).

Security — always

  • Never paste passwords or API keys in chat, email, or GitHub.
  • Secrets go only in Render → Environment (or gitignored .env.local on your PC).
  • If a key was shared by mistake → revoke it at the provider → put the new key in Render only.
  • Full rules: SECURITY-RULES.txt
